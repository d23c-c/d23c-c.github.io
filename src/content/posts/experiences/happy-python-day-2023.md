2023 年 3 月 4 日至 5 日，我參加 Happy Python Day 春季自主學習場。這次課程讓 Python 不再只是一門獨立的程式語言，而是能用來理解資安工具與處理資料的共同基礎。

## 從語法走向工具生態

原有心得包含 Python 基礎、迴圈、模組與物件導向，也記下編碼解碼、古典密碼及多種 Python 資安工具。比起一次記熟所有套件，更重要的是辨認它們的用途：Scapy 處理封包，Impacket 與網路協定相關，Volatility 聚焦記憶體鑑識，pwntools 則常見於受控環境中的程式互動與 CTF 練習。

舊紀錄把 Dshell 寫成遠端管理工具，這次整理修正為網路鑑識相關工具。工具名稱相似或同樣使用 Python，並不代表它們能解決相同問題。

## 語言基礎會決定能看懂多少範例

當時接觸 Base64、ASCII 與古典密碼練習，讓我看見字串、位元組和轉換函式的實際用途。回頭複習這些工具時，可以先讀懂一個最小範例，再調整輸入，觀察結果如何變化。語言基礎越清楚，越能判斷範例是在處理資料、操作協定，還是在分析證據。

延伸資源可參考講師的 [2023 Python 資安教材](https://github.com/MyFirstSecurity2020/SF2023A3)。沿著教材中的語言與資安應用主題，可以繼續補強讀懂範例所需要的基礎。
