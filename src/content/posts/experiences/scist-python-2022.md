2022 年 10 月，我參加 SCIST 資訊安全線上課程中的 Python 單堂研習。這是高中階段開始接觸資安時的一筆學習紀錄，時間早於高三上正式集中學習 Python 的階段。

| 活動時間 | 形式 | 角色 |
|---|---|---|
| 2022-10-15 | 線上單堂課程 | 學員 |

## 把程式語言當作理解工具的入口

這場課程在當年度系列中是第一堂課；我參加的是單堂線上研習，並非整個年度培訓。現在回頭整理，早期接觸 Python 的價值，在於開始理解資安工具背後也有輸入、處理與輸出的程式邏輯。即使還無法讀懂完整工具，只要能分辨變數、函式與資料型態，就能多看懂一部分範例。

## 本次補記的複習方向

當日練習未完整留存，以下是現在回看的複習方向：字串與位元組的區別、讀取檔案時的編碼，以及如何從錯誤訊息判斷問題位置。這些基礎會出現在解碼、封包分析與整理文字資料等工作中。

這堂課與之後的 Happy Python Day 可以放在同一條學習軌跡上：先接觸語言，再逐漸認識 Python 在資安領域中的用途，也逐漸能閱讀工具背後的程式邏輯。
